# MKAJ · Justitia

Лендинг постоянно действующего арбитража **Международный коммерческий арбитраж Justitia** (Республика Казахстан).

Тексты сверены с Законом РК от 8 апреля 2016 года № 488-V «Об арбитраже»: письменное соглашение, изъятия статей 8–9, обязательные сведения статьи 16, регламент.

Пока нет государственной регистрации, полный юридический адрес и утверждённый реестр арбитров на сайте не выдумываются.

Локально: `python3 -m http.server 8080 --bind 0.0.0.0` и открыть http://127.0.0.1:8080

Постоянный деплой на Vercel (`mkaj.vercel.app`) нужен токен аккаунта Vercel. Без него остаётся репозиторий и временная ссылка деплоя.
